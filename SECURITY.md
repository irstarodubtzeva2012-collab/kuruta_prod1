## 🎯 Общие принципы

### Defense in Depth
Многоуровневая защита: каждый слой имеет свою защиту. Нельзя полагаться на один барьер.

### Zero Trust
Внутренние сервисы не доверяют друг другу по умолчанию. Auth проверяется на каждом защищённом эндпоинте. RBAC — на каждой операции.

### Least Privilege
Каждый пользователь/сервис получает минимум прав, необходимых для операции.

### Security by Design
Безопасность встроена в архитектуру с самого начала, а не добавлена постфактум.

## 🔐 Аутентификация и авторизация

### Пароли
- **Алгоритм**: Argon2id (НЕ bcrypt, НЕ sha)
- **Параметры**:
  - memoryCost: 65536 (64 MB)
  - timeCost: 3
  - parallelism: 4
- **Соль**: Уникальная на каждую запись
- **Минимальная длина**: 8 символов
- **Требования**: uppercase, lowercase, digit

### JWT Tokens
- **Access Token**:
  - Алгоритм: HS256
  - Срок жизни: 15 минут
  - Хранение: localStorage или memory
- **Refresh Token**:
  - Алгоритм: HS256
  - Срок жизни: 7 дней
  - Хранение: httpOnly Secure SameSite=Strict cookie
  - **Ротация**: При каждом использовании
  - **При утечке**: Отзыв всей семьи токенов

### 2FA (TOTP)
- **Обязателен** для:
  - Вывода средств
  - Смены реквизитов вывода
  - Критических изменений аккаунта
- **Алгоритм**: TOTP (RFC 6238)
- **Период**: 30 секунд

### Rate Limiting
- **Auth endpoints** (login, register): 5 попыток/мин
- **API endpoints**: 100 запросов/мин на пользователя
- **Sensitive operations**: Отдельные лимиты

### RBAC (Role-Based Access Control)
Роли и их права:
- `guest` — регистрация, публичные страницы
- `creator` — создание кампаний, покупка мест
- `ambassador` — выполнение заданий, вывод средств
- `platform_owner` — продажа рекламных мест
- `moderator` — ручная проверка
- `finance` — обработка выплат
- `admin` — управление пользователями
- `superadmin` — системные настройки

**Принцип**: Роли назначаются явно, не наследуются по умолчанию.

## 🛡️ Защита данных

### Хеширование паролей
```typescript
import * as argon2 from 'argon2';

const hash = await argon2.hash(password, {
  type: argon2.argon2id,
  memoryCost: 65536,
  timeCost: 3,
  parallelism: 4,
});
```

### Шифрование чувствительных данных
- **TOTP секреты**: Шифруются перед сохранением
- **Реквизиты выплат**: Маскируются в логах
- **Персональные данные**: Шифруются при хранении

### Валидация входных данных
- **Zod схемы** на каждом эндпоинте
- **Whitelist полей**: Только разрешённые поля
- **Типизация**: Строгая проверка типов
- **Длина**: Ограничения на длину строк

### SQL Injection Protection
- **Только Prisma**: Parameterized queries
- **Raw SQL запрещён**: Кроме явно ревьюированных случаев
- **Валидация**: Все входные данные проверяются

### XSS Protection
- **React**: Автоматическое экранирование
- **CSP**: Строгая Content Security Policy
- **DOMPurify**: Для user-generated HTML (если появится)

### CSRF Protection
- **SameSite cookies**: Strict для refresh tokens
- **CSRF tokens**: Для state-changing операций
- **Origin validation**: Проверка Origin header

## 🌐 Сетевая безопасность

### HTTPS/TLS
- **TLS 1.3**: Только
- **HSTS**: Strict-Transport-Security header
- **Certificate**: Валидные сертификаты

### CORS
- **Whitelist**: Только разрешённые домены
- **НЕ `*`**: Никогда не использовать wildcard
- **Credentials**: true для authenticated requests

### SSRF Protection
Блокировка запросов к внутренним IP:
- `127.0.0.0/8` — Loopback
- `10.0.0.0/8` — Private Class A
- `172.16.0.0/12` — Private Class B
- `192.168.0.0/16` — Private Class C
- `169.254.0.0/16` — Link-local
- `::1` — IPv6 loopback

### Security Headers
```typescript
app.use(
  helmet({
    contentSecurityPolicy: {
      directives: {
        defaultSrc: ["'self'"],
        scriptSrc: ["'self'"],
        styleSrc: ["'self'"],
        imgSrc: ["'self'", "", "https:"],
      },
    },
    hsts: {
      maxAge: 31536000,
      includeSubDomains: true,
    },
  }),
);
```

## 📊 Мониторинг и аудит

### Audit Log
Все значимые действия логируются:
- Auth события (login, logout, refresh)
- Создание/изменение/удаление сущностей
- Финансовые операции
- Действия модераторов
- Смена ролей

**Формат**:
```typescript
{
  id: uuid,
  userId: string,
  action: string,
  entityType: string,
  entityId: string,
  before: jsonb,
  after: jsonb,
  ip: string,
  userAgent: string,
  timestamp: datetime
}
```

**Хранение**: Минимум 3 года, append-only.

### Логирование
**ЗАПРЕЩЕНО логировать**:
- ❌ Пароли
- ❌ Токены (access, refresh)
- ❌ Полные номера карт
- ❌ CVV коды
- ❌ Полные номера телефонов
- ❌ API ключи и секреты

**Разрешено логировать**:
- ✅ Маскированные email (user***@example.com)
- ✅ Маскированные телефоны (+7***12)
- ✅ Маскированные карты (****1234)
- ✅ ID пользователей и сущностей
- ✅ IP адреса
- ✅ User agents

### Мониторинг ошибок
- **Sentry**: Отслеживание ошибок
- **Structured logs**: JSON формат
- **Alerting**: Уведомления о критических ошибках

### Антифрод-сигналы
Автоматическое обнаружение:
- Дубликаты device fingerprint
- Одинаковые реквизиты вывода
- Подозрительно быстрое выполнение
- Повторяющиеся скриншоты
- Резкий рост аудитории
- Нестандартная активность

## 🚨 Обработка инцидентов

### Классификация инцидентов

**Critical**:
- Утечка данных пользователей
- Компрометация ключей/токенов
- Успешная SQL-инъекция
- Несанкционированный доступ к финансам

**High**:
- Попытка SQL-инъекции
- XSS атака
- Brute-force атака
- DDoS атака

**Medium**:
- Подозрительная активность
- Множественные неудачные попытки входа
- Необычные паттерны использования

**Low**:
- Единичные неудачные попытки
- Небольшие отклонения от нормы

### Процедура реагирования

1. **Обнаружение**: Мониторинг, алерты, сообщения пользователей
2. **Классификация**: Определение severity
3. **Сдерживание**: Блокировка атакующего, отзыв токенов
4. **Устранение**: Исправление уязвимости
5. **Восстановление**: Возврат к нормальной работе
6. **Анализ**: Post-mortem, извлечение уроков
7. **Отчёт**: Документирование инцидента

## 🔒 Security Checklist

### Разработка
- [ ] Все input валидируются через Zod
- [ ] Пароли хешируются через Argon2id
- [ ] JWT токены имеют короткий срок жизни
- [ ] Refresh tokens ротируются
- [ ] CORS настроен правильно
- [ ] Helmet используется с CSP
- [ ] Rate limiting настроен
- [ ] SSRF защита реализована
- [ ] SQL injection защита (только Prisma)
- [ ] XSS защита (React + CSP)

### Деплой
- [ ] TLS 1.3 только
- [ ] HSTS включён
- [ ] Секреты в .env (не в коде)
- [ ] .env в .gitignore
- [ ] Pre-commit hooks (gitleaks)
- [ ] Docker images сканируются
- [ ] Зависимости обновляются (Dependabot)

### Мониторинг
- [ ] Audit log включён
- [ ] Sentry настроен
- [ ] Алерты настроены
- [ ] Логи не содержат чувствительных данных
- [ ] Антифрод-сигналы мониторятся

- [ ] SQL injection тесты
