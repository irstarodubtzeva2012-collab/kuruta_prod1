# Security Audit Checklist

> Финальная проверка безопасности перед релизом

## ✅ Раздел 3 Конституции — Принципы безопасности

### 3.1 Defense in depth
- [x] Каждый слой имеет свою защиту
- [x] Auth + RBAC на каждом эндпоинте
- [x] Валидация на каждом уровне
- [x] Аудит-лог всех действий

### 3.2 Zero trust
- [x] Внутренние сервисы не доверяют друг другу
- [x] Auth проверяется на каждом защищённом эндпоинте
- [x] RBAC на каждой операции

### 3.3 Least privilege
- [x] Роли назначаются явно
- [x] Минимум прав для каждой операции
- [x] Проверка прав через middleware

### 3.4 Конкретные требования

#### Пароли
- [x] Argon2id (не bcrypt, не sha)
- [x] Уникальная соль на запись
- [x] memoryCost: 65536, timeCost: 3, parallelism: 4
- [x] Минимальная длина: 8 символов
- [x] Требования: uppercase, lowercase, digit

#### JWT
- [x] HS256 с длинным секретом
- [x] Access token: 15 мин
- [x] Refresh token: ротация при каждом использовании
- [x] Refresh хранится в httpOnly Secure SameSite=Strict cookie
- [x] При утечке — отзыв всей семьи токенов

#### 2FA
- [x] TOTP для финансовых операций
- [x] TOTP для смены реквизитов
- [x] Обязателен для критических операций

#### Rate limiting
- [x] Auth: 5 попыток/мин
- [x] API: 100 req/мин на пользователя
- [x] Sensitive-операции: отдельные лимиты

#### Helmet + CSP
- [x] Строгая Content Security Policy
- [x] Без unsafe-inline где возможно
- [x] HSTS с preload
- [x] Referrer-Policy
- [x] X-Content-Type-Options: nosniff
- [x] X-XSS-Protection

#### CORS
- [x] Whitelist доменов
- [x] НЕ `*`
- [x] Credentials: true

#### SQL-инъекции
- [x] Только Prisma parameterized queries
- [x] Raw SQL запрещён
- [x] Валидация всех входных данных

#### XSS
- [x] React по умолчанию экранирует
- [x] CSP restricts inline scripts
- [x] DOMPurify для user-generated HTML (если появится)

#### CSRF
- [x] SameSite cookies
- [x] CSRF-token для state-changing операций

#### SSRF
- [x] Запрет исходящих запросов к внутренним IP
- [x] Блокировка 127.0.0.0/8, 10.0.0.0/8, 169.254.0.0/16, etc.
- [x] Middleware для проверки URL параметров

#### Валидация
- [x] Zod-схемы на каждом эндпоинте
- [x] Whitelist полей
- [x] Проверка типов
- [x] Ограничения на длину

#### Файлы
- [x] Проверка MIME по содержимому (magic numbers)
- [x] Лимит размера
- [x] ClamAV-интерфейс
- [x] Хранение вне webroot

#### Секреты
- [x] `.env` в `.gitignore`
- [x] `.env.example` без значений
- [x] Pre-commit hook (husky + gitleaks)
- [x] Секреты никогда в коде

#### Логи
- [x] Структурированные (JSON)
- [x] НИКОГДА не логировать пароли
- [x] НИКОГДА не логировать токены
- [x] НИКОГДА не логировать реквизиты карт
- [x] Маскирование обязательно

#### Transport
- [x] TLS 1.3 только
- [x] HSTS
- [x] Valid certificates

#### Зависимости
- [x] Dependabot
- [x] `npm audit` в CI
- [x] Критические уязвимости блокируют merge

### 3.5 Финансовая безопасность
- [x] Все операции через FinancialJournal
- [x] Баланс — вычисляемое поле
- [x] Все операции в ACID-транзакциях
- [x] Двойная запись (double-entry)
- [x] SELECT ... FOR UPDATE при работе с балансом
- [x] Идемпотентность через idempotencyKey
- [x] Аудит-лог всех изменений денег
- [x] Минимальный вывод: 500 ₽
- [x] Смена реквизитов → временная блокировка

### 3.6 Антифрод-сигналы
- [x] Несколько аккаунтов с одинаковыми device fingerprint
- [x] Одинаковые реквизиты вывода у разных пользователей
- [x] Подозрительно быстрое выполнение заданий
- [x] Повторяющиеся скриншоты-подтверждения
- [x] Резкий рост аудитории без истории
- [x] Нестандартная активность
